# EffectCraft Motion Films: adapted directing skill

## When to use
Plan and produce a motion-graphics reel or short film in EffectCraft, keeping the storytelling, shot planning, sound, pacing and review teachings of Lemo-Opuscar without its code-from-scratch renderer. This is the user's requested adaptation, not a skill literally named "story" from the reel.

## How to use
Read `authored/effectcraft-motion-films/SKILL.md`, then give Claude the actual story, destination, length and confirmed brand constraints. For example:

> Use effectcraft-motion-films for this 20-second vertical explainer. Check the EffectCraft connection, plan a clear story, and build/render through EffectCraft. Preserve my existing project and publishing settings. Do not install software or change configuration silently, spend money, or fall back to coding a renderer.

The skill checks available tools first and uses discovery for installed-version commands. Routine setup is subject to the owner's authority; adding this file is not permission to install or reconfigure anything. If EffectCraft remains unavailable, surface the blocker rather than substitute a different production pipeline. Keep Konsiar and Velocitas in their own projects.

## What is included
The complete reviewed adapted skill is in `authored/effectcraft-motion-films/SKILL.md`. `prepare_library.py` copies it and this guide into one new library folder with checksum verification. No upstream prompts, Lemo runtime, style collection or EffectCraft application are fetched by intake.

The existing entry 13 covers ArtCraft tool controls, including EffectCraft; this entry supplies the directing workflow rather than duplicating those controls. The other motion-design entries remain separate alternatives, not a stack to activate automatically.

## Setup, cost and verification limits
The skill uses the free open-source EffectCraft application and its CLI/MCP connection. On macOS the CLI may be a separate release download. The app was previously reported installed, but present CLI/MCP readiness is not established by that history. See the source's current setup guidance and inspect local state before relying on it.

No paid dependency, model API or new account is required by this adapted workflow. Existing Claude usage still applies. Voice/music assets come from existing permitted sources, not a silently added paid TTS service. The Lemo Node/ffmpeg/Python rendering chain is deliberately not part of this adaptation.

This is an authored workflow checked against current documentation, not an end-to-end rendered test on the user's Mac. EffectCraft is alpha; confirm installed capabilities and inspect actual frames/output. Exact tool behavior and supported formats may change. No device install or production render was performed during library publication.
