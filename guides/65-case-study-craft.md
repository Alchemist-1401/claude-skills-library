# Case study craft

## When to use
Write a customer case study that actually sells. Most case studies lead with metrics and fail; this method leads with the customer's before-state and prior doubts so the reader sees themselves, maps each common objection to a story moment that disproves it, and uses numbers as supporting evidence. Use for case studies, customer stories, testimonial pages or proof sections for a site, deck, post or reel script. Free, no tools beyond a Markdown file.

## How to use
Read `authored/case-study-craft/SKILL.md`, then give it the engagement, for example:

> Use case-study-craft for a B2B service business. Customer: a client who doubted automation would work for them. I will paste my interview notes and project numbers; draft the full web version, then a short caption version. Real facts only; I will get the customer's approval before anything is used.

The skill runs five steps: pick the subject by reader-mirror rather than size, interview for before-state and doubts, map objections to story moments, structure the draft (mirror, before, turning point, after with evidence, quotes, soft close), then adapt per surface. Output is always a draft for the user's review; the featured customer approves final text, and nothing is sent or published. Outreach sequences stay with entry 59, educational articles with entry 64, persuasion principles with entry 41.

## Setup and local intake
A normal Markdown file in `authored/case-study-craft/SKILL.md`. No installer, account, dependency, API key or paid service. The standard `prepare_library.py` intake copies this guide and the authored skill with checksum verification; it does not activate anything.
