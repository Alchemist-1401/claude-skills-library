# Source packages

These five numbered ZIP parts contain the reviewed scoped source snapshots, per-entry usage README files, separate project references and source audit. Keep all five parts together. From the repository root run `python3 prepare_library.py` to verify and expand them into one local `library/` folder. This does not enable skills or run upstream code. Do not open a single part as a complete ZIP. See the root catalog for instructions and honest source-linked/incomplete cases.
