# Entry point

Read README.md and CATALOG.md, then the relevant file in guides/. This is a private reference library, not an active plugin or a universal project configuration.

For local intake, prepare_library.py retrieves only the source paths listed in manifests/ at pinned commits, verifies file hashes and creates one new library/ folder. It copies this repository's authored texts/project references too. It never enables or executes upstream skills. Do not look for a bundled archive: sources are retrieved from their original public repositories.

Choose the smallest relevant skill for the user's task and work in the intended project. Preserve reviewed free scopes, source notices and project boundaries. Existing user authorization remains unchanged; opening this library does not grant new install, send, publication, spending or account-change authority. Historical settings and prices are not verified current facts.

Konsiar stays in Konsiar. Velocitas stays in Velocitas, never the owner's personal Instagram. Project companions are background for a requested task, not installable skills. Lisaan is incomplete without its original reference ZIP. Some entries stay source-linked; manifests/ specifies exactly which files are retrieved. Private GitHub access requires authentication.
