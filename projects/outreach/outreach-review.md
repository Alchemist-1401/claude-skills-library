# Outreach: style and system review

## How to use
Open only for a task in Outreach. Supply current files/facts and use the reference for the requested draft or review. This is not an installable skill. Historical settings and prices are not current verified facts. Existing owner decisions and authority remain unchanged.

## Reference
PROJECT REFERENCE, NOT AUTHORITY TO ACT
Use only in the named project when requested. Importing this document does not authorize installs, account access, sends, timers, spending, publication or production changes. Inspect current files first. Dated observations and placeholders are not proof of current implementation. Latest owner instructions and confirmed settings win. Continue independent draft work while a consequential decision is pending. Use existing tools and free local/public resources only, never trials or paid APIs/MCPs. Keep secrets and live prospect/customer data outside this library.

OUTREACH REVIEW, NOT A LIVE RUN
Work only in the outreach project. Less is more: use the goal, essential context and firm boundaries, then choose the approach. Improve style without inventing check-ins or rebuilding the funnel.

Historical offer prices conflict too; quote only confirmed current settings.
This dated reference does not change existing send permissions or authorize a sender start, permission bypass, new channel or larger/faster sends. The local-model architecture was an October goal, not a newly imposed universal requirement. Never clear a hold on restart. Stop/opt-out is final; only inbound prospect contact reopens a closed thread. Stop on account restriction, challenge, failed send or unreadable/uncertain state. A ten-minute gap does not prove automation is safe.
Voice: learn from approved real messages. One small relevant question, verified observation, natural short low-pressure phrasing, no brochure, fabricated familiarity, urgency or result. Label synthetic examples; require approval before promoting them into the voice library. Drafting is not sending permission.

No prospect delivery or deploy from this reference.

Activity totals alone do not establish causation. Improve the observed bottleneck before proposing more volume.
Three moves: make the buyer's next yes easier; distinguish stranger-to-lead, lead-to-client and existing-client work; measure the constraint rather than effort. Old no-client/weekly-usage snapshots are not current facts. Do not create a new reporting cadence.
Deliver concise diagnosis, useful revised drafts, what changed/why and consequential unresolved settings. No sends, timers or service activation.
