## How to use
Open only for a task in Outreach. Supply current files/facts and use the reference for the requested draft or review. This is not an installable skill. Historical settings and prices are not current verified facts. Existing owner decisions and authority remain unchanged.

## Reference

LOCAL RELIABILITY CHECKLIST
Inspect actual runtime version, hardware, memory/disk, model, server binding, health and startup configuration. Old model IDs/OS/RAM claims and build commands are not a verified current recipe. Check upstream before any install proposal.
Historical local-model setup called for loopback inference without a public tunnel/proxy or automatic cloud fallback. Verify current authorized architecture rather than imposing this as a new restriction. Use sequential requests if the actual runtime requires it. A local OpenAI-compatible endpoint does not mean a paid cloud API.
Separate scouting/drafting from live sending. After restart default no-send; supervisors never clear holds or restart live-send mode. Check actual power/sleep/network behavior; do not promise 24/7 from a terminal process.
Persist queue/log/hold state with atomic durable writes and idempotency keys. One runner lock. Record send attempted before action and observed result afterward. Quarantine uncertain outcomes; reconcile the actual conversation before retry. A missing success receipt never proves no send happened.
Before an authorized send, read the actual conversation identifier and composer, compare against the approved recipient/text and refuse unreadable/mismatched state. This reduces risk, not guarantees safety. Use fixture/isolated test pages; no real-composer dry run unless every submit path is disabled.
After sleep/network gaps, resume without catch-up bursts. Session expiry requires normal login, no plaintext passwords. Report health, last cycle, queue, holds, quarantines and real logs. Label mocked/self-tested, live read-only or untested evidence.
Learning uses context, not assumed weight fine-tuning: approved real first-touch/follow-up/reply examples, concise voice prompt and draft/correction pairs. Approval controls the example library.
